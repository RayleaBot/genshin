# 验收与交付计划

本计划承接主仓库 RayleaBot 的游戏插件返工计划中尚未完成的 R7 阶段（验收与交付）；R0 至 R6c 已完成，其内容随主仓库文档删除，不再保留。记录日期：2026-10-02。

## 验收口径

- 用户可见功能以 Windows 实例上的 Core、真实账号和真实聊天消息验收，并与上游同一命令的输出对照；合成数据测试只用于回归，不能替代验收。
- 对照的上游仓库与固定提交见 [DATA_SOURCES.md](../DATA_SOURCES.md)，下文括号内写上游页面或模块名。
- 与上游有意不同的行为见文末一节，对照时不算缺陷。
- 验收结束时提交本仓库，不推送。

## 受限事项

- 海外账号与区服：海外导入、固定端点与设备验证尚无真实海外账号验收；国服先交付。
- 国服网页兑换：参考实现只有游戏内兑换，没有已验证的国服网页入口；海外兑换端点待海外账号验收。
- 云游戏独立授权：云原神签到需要独立的 `x-rpc-combo_token`，上游说明要求云客户端授权，没有以米游社凭据换取的已验证路径；功能默认关闭。
- minigg 地图服务：自 2026-09-22 起 TLS 握手失败，回复说明原因；服务恢复前地图不可验收。
- Linux 与 macOS：只有交叉构建，未实机运行。

## 与上游的有意差异

- 只响应宿主通用前缀，帮助与版本写作 `#原神帮助`、`#原神版本`；通用前缀下的“帮助”归宿主内置菜单。
- Yunzai 与 miao 重叠的写法按 Miao-Yunzai 处理：miao 规则收下的写法出 miao 页面，miao 不收的写法仍出 Yunzai 页面；Yunzai 把“角色统计”“武器统计”改写为“池统计”后再匹配；没有喵喵版抽卡开关。
- 群排行在群内查看面板时自动登记，没有提交排行与退出排行；圣牌查看即登记，没有圣牌提交与退出。
- 不提供上游没有的队伍计算、保存月报、资产记录（并入 `#更新充值记录`）、自动同步、同步进度、停止同步、同步抽卡、图鉴图、公开信息，以及“空格加期数”写法；“获取抽卡记录”“获取充值记录”“导出充值记录”会在私聊发送含 authkey 的链接，不提供。
- `#更新抽卡记录` 按上游写法在原聊天回复结果，不带全量与增量参数；抽卡记录按所指定、当前使用或被 @ 用户的 UID 读取档案，不按 CK 隐藏。
- 体力推送改为逍遥插件的群内 @ 推送；戳一戳由设置项控制、默认开启，没有“戳一戳 开启/关闭”与“互动”写法。
- 深渊汇总页去掉关于上传深渊与胡桃 API 统计的两条说明；“本期深渊X层”“往期深渊X层”按期数处理（上游只认上期）。
- CK 与 SToken 只经扫码登录或管理页加密导入；聊天中出现凭据时提示撤回。
